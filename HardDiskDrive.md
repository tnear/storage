# Hard Disk Drive

A hard disk drive (HDD) is a traditional data storage device that uses rapidly rotating magnetic platters to store and retrieve digital information on a computer.

See also: [flash memory](FlashMemory.md)

## CMR vs SMR

### CMR
Conventional Magnetic Recording (CMR) is how hard drives have worked for most of their history: the disk platter is divided into concentric circular tracks, and each track is written with a small gap between it and its neighbors. There is enough space that the write head can safely rewrite any single track without disturbing the ones next to it.

### SMR
Shingled Magnetic Recording (SMR) packs tracks tighter by overlapping them. A write head needs a certain width to reliably write a track, but a read head can get away with reading a much narrower strip. So instead of leaving that full gap between tracks, SMR drives write each new track so it overlaps part of the previous one — like shingles on a roof.
